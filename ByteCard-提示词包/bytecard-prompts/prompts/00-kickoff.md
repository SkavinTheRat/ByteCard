# 阶段 0 · 开场（每次新会话都先贴这个）

> 用途：Codex 每次新会话只会自动读 `AGENTS.md`，不一定会读 `spec/`。
> 这条开场白负责把它「扶正」，成本极低，但能省掉大量跑偏。

---

我们是 ByteCard 项目，一个 React Native + Expo 的知识卡片 App。

先做三件事，做完就停下来，**不要写任何代码**：

1. 读 `AGENTS.md`（技术栈、目录铁律、禁止事项）。
2. 读 `spec/01-data-model.md`、`spec/02-deck-schema.md`、`spec/03-design-tokens.md`。
3. 用 15 行以内回答我：
   - 这个项目的技术栈有哪 5 个不能替换的选择？
   - 组件的分层铁律是什么（数据从哪一层到哪一层）？
   - 你要改的代码里，颜色应该从哪来？
   - 你看到 `prompts/` 里有哪些阶段、当前应该做哪个？

答完等我给具体阶段的 prompt。

---

## 附：如果它答错了

这是判断模型有没有真的读懂上下文的试纸。典型错误答案与纠正话术：

| 它可能这么说 | 说明 | 你回它 |
| --- | --- | --- |
| 「可以用 Redux 管理状态」 | 没读 AGENTS.md | `状态只用 Zustand，重读 AGENTS.md 第 3 节。` |
| 「颜色可以直接写十六进制」 | 没读 tokens 规范 | `颜色只能来自 src/theme/tokens.ts，重读 spec/03 第 1 节。` |
| 「组件里直接查 SQLite」 | 不理解分层 | `SQL 只能出现在 src/db/，组件只调 repository。` |
| 开始列代码 | 没听「不要写代码」 | `停，我只问了你 4 个问题，先回答。` |

第一轮就校正过来，后面 7 个阶段会顺很多。
